## Om Flyttstäd Göteborg

Flyttstäd Göteborg erbjuder flyttstädning till fast pris från 1 995 kr efter RUT, med garanti mot besiktning. Auktoriserad firma med F-skatt och försäkrad personal. Vi servar hela Göteborg och kringliggande kommuner — inklusive Mölndal, Partille, Lerum och Kungälv. Boka online på två minuter och få bekräftelse direkt.

→ [flyttstadgoteborg.se](https://flyttstadgoteborg.se)

## Stack
- Astro 7
- Netlify, med Cloudflare framför
- Resend · PostHog
